Arquitectura de Google Sheets & Next.js Data Cache

Cómo funciona el backend de datos sin agotar las cuotas de Google Cloud.

1. Next.js Data Cache (`unstable_cache`)

Las consultas se realizan desde Server Components usando google.auth.JWT y se cachean durante 300 segundos (5 minutos) en el servidor de Next.js.

revalidate: 300 // 5 minutos
tags: ['google-sheets-data', 'obras']

Esto reduce el consumo de cuota de Google de 10.000 peticiones diarias a menos de 50, garantizando alta velocidad y disponibilidad ininterrumpida.

2. Mapeo de Pestañas Configuradas

  • Pestaña "Obras" Obras!A:P (16 columnas)
  • Pestaña "Contratistas" Contratistas!A:H (8 columnas)
  • Pestaña "Certificaciones" Certificaciones!A:H (8 columnas)
